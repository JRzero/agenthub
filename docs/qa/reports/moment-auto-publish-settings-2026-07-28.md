# 朋友圈自动发布设置 QA

## 范围

- 路由：`http://localhost:3002/operations?module=moments`
- 数据模式：Live
- 入口：应用运营 → 朋友圈管理 → 自动发布设置
- 验证日期：2026-07-28

## 功能验证

- 朋友圈管理工具栏显示“自动发布设置”入口。
- 弹窗只提供已发布平台当前版本的 Agent；真实工作空间共显示 16 个可用 Agent。
- 打开弹窗后通过 Agent 级 GET 接口读取当前设置。验证 Agent 返回“自动发布未开启”，可进入“AI 一键排期”状态。
- 当前朋友圈 Agent 筛选为已发布 Agent 时优先沿用；否则回退到第一个已发布 Agent。
- 未发布 Agent 不会成为自动发布目标。
- Esc 可关闭弹窗，入口可再次正常打开。
- 生成、重新生成和关闭均复用既有后端契约；错误分支不会覆盖当前已加载排期。
- 本次 Live QA 只执行读取，没有生成排期、关闭排期或发布朋友圈。

## 视觉与响应式验证

- 默认尺寸下弹窗保持居中，标题、Agent 选择、状态、主操作和底部说明层级清晰。
- 1280 × 720 内容视口下弹窗完整可见，无横向溢出；内容超出时由弹窗主体独立滚动。
- 浏览器控制台无错误或警告。

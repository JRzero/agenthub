## Deviations and Risk Register

- The mock's notification count is intentionally omitted because it has no live source.
- The written 200px sidebar decision overrides the mock's wider illustrative sidebar.
- The current route map has no global publish-center route and only one governance route. The shell does not invent fake destinations; downstream work can add entries only after a real route contract exists.
- Remaining legacy palette occurrences are page-owned and outside LYN-004-A: Agent distribution channel decoration, Agent memory visualization, Analytics chart series, Resource skill categories, Revenue fixtures/views, and Workbench chart series. Shared shell and base UI no longer use purple/indigo as primary emphasis.
- No backend capability, API, DTO, model, permission, storage key, request header, or creation field changed.

## Downstream Readiness

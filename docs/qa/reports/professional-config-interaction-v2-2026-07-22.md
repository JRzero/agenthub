## 布局与交互检查

- 桌面展开态列宽契约：配置导航 184px、预览 280px。
- 桌面收起态列宽契约：配置导航 184px、预览轨道 56px。
- 1024–1279px 桌面宽度默认收起预览，避免挤压中间编辑区。
- 构建路由外层禁止文档滚动；配置导航、编辑内容、预览消息分别拥有纵向滚动区域。
- 内部滚动区域隐藏浏览器常驻滚动条，但继续支持滚轮、触控板和键盘滚动；桌面配置导航禁止横向偏移，避免图标与文字被裁切。
- 桌面断点进入或窗口尺寸变化时会主动清除移动端遗留的导航横向滚动位置。
- 预览栏、标题区、正文和输入区均限制在固定栏宽内；长文案强制换行，不再把收起按钮或正文撑出视口。
- 构建页三栏使用负外边距抵消工作空间内边距时，外层不再裁剪左右边缘；左侧分组标题、图标以及右侧预览收起按钮均完整可见。
- 未保存更改时禁止发送预览，并提示先保存草稿。
- 技能阶段变更继续使用既有阶段技能接口即时持久化；普通 Agent 字段仍由顶部“保存草稿”统一提交。

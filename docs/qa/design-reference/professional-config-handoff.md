## 1. 背景与目标

本次调整针对 AgentHub 的「Agent 专业配置模式」，目标是让创作者能更方便地配置自己的 Agent，并降低构建面板的操作复杂度。

核心原则：

- 保留当前专业配置模式的信息架构，不扩展新的一级模块。
- 每个配置项聚焦当前任务，减少页面滚动和注意力分散。
- 右侧预览只承担实时反馈，不承载版本切换、会话管理或复杂测试能力。
- motherland 不是 Client 端配置，而是 Agent 视觉资产生成工具，应放在「媒体资产」配置项中。

## 2. 本次开发范围

本次只调整 Agent 构建页的专业配置模式，重点包括：

- 保留顶部全局信息栏。
- 保留 Agent 信息头部、状态标签、主操作按钮和一级页签。
- 保留左侧应用主导航图标栏。
- 保留构建页内的专业配置菜单样式。
- 将右侧面板收敛为单一「实时预览」。
- 将 motherland 入口放入「媒体资产」页，用于生成头像、角色设定稿与漫画设计稿。

不在本次范围：

- AI 共创式快速创建。
- 朋友圈配置。
- Client 适配或发布端配置。
- 会话管理、运营数据、收益、积分分成。
- 角色人格的进一步拆分。
- 新增独立 motherland 一级模块。

## 3. 页面整体结构

页面保持三段式工作台结构：

```text
左侧主导航图标栏
+ 构建页专业配置菜单
+ 中间配置工作区
+ 右侧实时预览
```

建议宽度关系：

- 左侧主导航图标栏：保持当前宽度。
- 专业配置菜单：保持当前宽度与样式。
- 右侧实时预览：收窄到约 320-360px。
- 中间配置工作区：使用剩余宽度，成为主要操作区域。

页面顶部结构保持：

- 全局信息栏：AgentHub Logo、Workspace、搜索/文档/通知/设置、用户信息。
- Agent 信息区：头像、名称「霸王龙小玩伴」、发布状态、核心资产版本、准备度。
- 操作按钮：重置、保存草稿、保存并测试。
- 一级页签：概览、构建、测试评估、版本、发布。

## 4. 专业配置菜单

菜单样式保持当前设计稿，不改变视觉结构、行高、图标风格、分隔线、选中态和缩进。

菜单内容调整为实际配置项：

```text
身份与人设
- 身份信息
- 角色人格

运行配置
- 运行配置

能力配置
- 技能
- 知识

- 测试评估
- 版本与发布
```

## 5. 媒体资产页

### 5.1 页面定位

「媒体资产」用于管理 Agent 的视觉资产，包括：

- 当前头像。
- 角色设定稿。
- 漫画设计稿。

motherland 是该页面内的生成工具入口，用于生成或更新这些视觉资产。它不作为独立模块出现。

### 5.2 页面标题

标题：

```text
媒体资产
```

辅助说明：

```text
管理 Agent 的头像、角色设定稿与漫画设计稿
```

### 5.3 当前头像区域

展示内容：

- 当前头像缩略图。
- 状态：已保存。
- 说明：用于身份信息与实时预览。

操作按钮：

- 从资产选择。
- 上传。
- 使用 motherland 生成。

交互要求：

- 「从资产选择」用于从已有媒体资产中选择头像。
- 「上传」用于上传本地图片作为头像。
- 「使用 motherland 生成」进入 motherland 生成流程，生成结果回填为候选头像，创作者确认后才替换当前头像。
- 未确认前，不直接覆盖当前已保存头像。

### 5.4 角色设定稿区域

区域标题：

```text
角色设定稿
```

辅助说明：

```text
用于展示角色的整体形象、表情、动作与配色方案
```

展示方式：

- 使用横向卡片列表展示设定稿。
- 每张卡片包含缩略图、名称、版本号、生成日期、更多操作入口。
- 默认展示 2-3 张最近设定稿。

操作按钮：

```text
生成设定稿
```

交互要求：

- 点击后进入 motherland 设定稿生成流程。
- 生成结果作为新的设定稿资产保存到媒体资产页。
- 不自动改写角色人格配置，只作为视觉资产沉淀。

### 5.5 漫画设计稿区域

区域标题：

```text
漫画设计稿
```

辅助说明：

```text
用于展示漫画分镜、场景与风格设定
```

展示方式：

- 使用横向卡片列表展示漫画稿。
- 每张卡片包含缩略图、名称、版本号、生成日期、更多操作入口。
- 默认展示 2-3 张最近漫画稿。

操作按钮：

```text
生成漫画稿
```

交互要求：

- 点击后进入 motherland 漫画稿生成流程。
- 生成结果作为新的漫画设计资产保存到媒体资产页。
- 不进入发布流程，不直接影响 Client 端展示。

## 6. motherland 边界

motherland 在本次设计中的产品定位：

```text
Agent 视觉资产生成工具
```

它负责：

- 生成 Agent 头像。
- 生成角色设定稿。
- 生成漫画设计稿。

它不负责：

- 配置朋友圈。
- 配置 Client 适配。
- 管理发布渠道。
- 管理会话或运营数据。
- 替代角色人格配置。

开发实现时，motherland 入口应嵌入媒体资产页，不要新增顶部导航、左侧主导航或独立页面入口。

## 7. 右侧实时预览

右侧只保留「实时预览」面板。

需要移除：

- 当前草稿 / 已发布版本切换。
- 清空对话按钮。
- 多轮复杂会话管理能力。

保留内容：

- 标题：实时预览。
- 说明：使用已保存配置。
- Agent 头像。
- Agent 名称。
- 一条简短开场消息。
- 底部输入框。

实时预览的作用：

- 让创作者看到当前头像、名称和基础角色表现。
- 作为配置反馈，不作为完整测试评估工具。

测试评估能力仍放在一级页签「测试评估」中处理。

## 8. 状态与保存规则

建议状态：

- 已保存：当前资产已进入 Agent 配置。
- 生成中：motherland 正在生成资产。
- 待确认：生成结果已返回，但尚未被创作者确认使用。
- 失败：生成失败，可重试。

保存规则：

- 上传、选择或生成的新头像，在用户确认前只作为候选资产。
- 角色设定稿和漫画设计稿生成后进入媒体资产列表。
- 保存草稿时，保存当前已确认的媒体资产引用关系。
- 保存并测试时，先保存草稿，再进入测试流程。

## 9. 视觉与交互要求

视觉风格跟随当前设计稿：

- 白色与浅灰为主背景。
- 蓝色作为主操作与选中态。
- 绿色用于成功、在线、已保存状态。
- 保持轻量边框，少用阴影。
- 不使用大面积渐变、营销化卡片或装饰性背景。

交互要求：

- 中间配置区是主焦点。
- 右侧预览不抢占操作注意力。
- 同一页面内信息不要堆叠过多，保持卡片尺寸稳定。
- 中文文案必须完整显示，不允许按钮文字、菜单文字、卡片标题溢出。
- 页面在 1440px 宽度下应无需横向滚动。

## 10. 验收标准

开发完成后，按以下标准验收：

- 顶部信息栏、Agent 信息头、主操作按钮、一级页签均保留。
- 专业配置菜单样式未改变，内容与本文件第 4 节一致。
- 「媒体资产」被正确选中。
- 右侧只有「实时预览」，没有草稿/已发布切换和清空对话。
- 右侧预览宽度明显小于原稿，中间配置区更宽。
- 媒体资产页包含当前头像、角色设定稿、漫画设计稿三个内容区域。
- motherland 入口只出现在媒体资产相关操作中。
- 生成资产不直接覆盖已保存头像，必须经过确认。
- 页面无明显文字重叠、按钮溢出、布局挤压。
- 1440px 桌面宽度下核心操作无需频繁滚动。

## 11. 待产品确认项

以下问题暂不阻塞首版开发，但需要产品后续确认：

- motherland 生成流程采用弹窗、抽屉还是独立步骤页。
- 生成结果是否需要支持版本对比。
- 头像、角色设定稿、漫画设计稿是否共用同一个素材库表结构。
- 媒体资产是否需要权限或审核状态。
- 角色设定稿是否需要在「角色人格」页中以只读方式引用展示。

## MODIFIED Requirements

### Requirement: Asset lifecycle navigation

The Agent Asset workspace SHALL provide functional Overview, Build, Test Evaluation, Versions, and Distribution routes within the selected workspace and Agent context.

#### Scenario: Open Distribution

- **WHEN** a creator selects Distribution for an Agent Asset
- **THEN** the selected Agent header and lifecycle navigation SHALL remain visible
- **AND** the route SHALL show the multi-client release console instead of a placeholder

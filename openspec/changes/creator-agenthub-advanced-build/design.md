# Design

Advanced controls remain inside the existing Build section rail. Runtime uses one Provider control for Cloud Agents: concrete backend catalogue entries are grouped by supplier, while custom compatibility protocols remain in the same selector and mutually exclusive with catalogue Providers. The model control lists models belonging to the selected supplier. Selecting a model maps back to the concrete backend Provider configuration before serialization. Edge Agents continue to show their credential panel. Provider selection scopes the model dropdown but does not silently persist the Provider default model: an empty model override inherits the system configuration. Temperature follows the same contract through `null`, with an explicit “使用系统默认” control. Media uses a canvas cropper without adding a dependency. Skills preserve all three backend stages and expose both Creator-global config scopes and Agent-level overrides through a validated JSON editor.
